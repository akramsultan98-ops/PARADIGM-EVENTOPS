# User guide

## Signing in & navigation
Sign in with your Paradigm account. The left sidebar shows only what your role can use; the header holds the **project context** switcher, global search, quick actions, language toggle (English / عربي), notifications and your profile. On phones use the ☰ menu.

## Account Managers
1. **Projects → New project**: brief, dates & venue (Cairo time), team & departments (lead + input due date), budget & scope → *Create project*. Departments are notified.
2. Track progress in **Account Management** and the project **Overview**.

## Department teams
- Your **Dashboard** is your department workspace plus "My projects / tasks / required information / notifications".
- **Production**: *ADD PRODUCTION REQUIREMENTS* opens the 10-step form. Enter panels, frame members and paint surfaces from the drawing — the system only calculates what you specify. Drafts autosave; *Save draft* stores it in the project.
- **Describe in your own words**: Project → Department Inputs → type a description → *Extract draft*. Review the evidence and follow-up questions, correct the fields, attach the drawing, then *Confirm & submit*.
- **AV**: *ADD AV REQUIREMENTS*, pick inventory models (availability shown). **Logistics**: *Add cargo*. **Accommodation**: *Add guest* (shared rooms use the same label). **Creative**: *Add branding item*, record client approval.
- Managers approve their department's submissions in the **Approval Center** or on the submission itself (Approve / Request info / Reject).

## Project Managers
- **Generate plan** (project header) runs all engines and opens **Master Planning**: errors, warnings, clarification questions per department, version history.
- Explore **BOQ**, **Manpower**, **Logistics**, **Timeline**, **Gantt** (zoom, department filter, critical path, dependencies), **Risk Register**, **Budget**. Every calculated number has a *trace* link showing formula, inputs and assumptions.
- **What-if**: ask e.g. "What if we only get one setup day?" — results never change the approved plan.
- **Request change**: resize an item, change participants/budget/dates or mark a vehicle unavailable — the system shows the impact and routes the approval. Approved changes create a new plan version for review.
- **Reschedule** a task from the Timeline; dependent tasks move and deadline breaches are reported.
- **Approve** the plan when department technical approvals are complete (acknowledge any open errors explicitly).

## Procurement & Finance
Procurement prepares RFQs (PDF), records quotations, compares suppliers, selects one and submits for approval; Finance approves; Procurement marks *ordered* and records deliveries. Nothing is sent to vendors automatically.

## Site execution (mobile)
**Live Execution** → choose the project → *Start*, *+25%*, *Done*, *Delay* (the system proposes recovery options), *Report issue*, *Record actual*, *Site photo*. **Actual vs planned** shows accuracy per category.

## Exports
Project header → *Master workbook* (20 sheets) or ⋯ → *PDF plan report*; **Reports** offers department sheets and CSV; RFQs from the procurement board.

## AI assistant
Ask about readiness, missing information, BOQ, crew, transport, schedule, risks or what-if scenarios. It answers from the planning engines and states which tools it used. Without an AI key it runs in rule-based mode.
